# 家长端自动化与专注使用管理

## 范围与授权

通过已登录的「讯飞AI学」家长 App，查看必要的使用汇总，提出适合当前学段的应用保留、限时或关闭建议。目标是减少无目的连续观看与任务切换，保护作业、睡眠、运动和亲子时间；不以“完成更多 App 任务”代替专注。

- 首轮只读。分析使用习惯不等于授权立即保存限制；先列出应用、原设置、拟调整值、影响及恢复办法，再取得家长确认。
- 家长端的禁用入口不等于 Android `pm disable-user`。不以 ADB、卸载、修改系统设置或关闭管理服务代替家长端配置。
- 不抓包、提取登录 token、读取 App 私有数据库或绕过家长验证。登录和验证码由用户自行完成。
- 仅查看任务所需的应用名、统计日期、时长、使用时段和权限。不要展开孩子的照片、作品、聊天、录音或具体答题内容。
- 孩子的当期能力、日常记录、应用黑白名单和试行参数属于个人动态信息，不固化进共享 Skill。原始截图仅留工具临时目录或本地忽略目录，不上传、不入库。

## 工具与入口

Mac 上家长 App 的 bundle ID 为 `com.iflytek.aistudyclient.parentcontrol`。先确认本机已安装、可运行并登录；不能由 App Store 兼容性声明推断所有功能均能自动化。

```bash
orca status --json
orca computer capabilities --json
orca computer list-apps --json
orca computer list-windows --app com.iflytek.aistudyclient.parentcontrol --json
orca computer get-app-state --app com.iflytek.aistudyclient.parentcontrol --json
```

执行前读取当前环境的 `computer-use` skill。App、窗口和元素均按当前状态定位：

1. 优先可访问性树中的导航控件；选定窗口后持续带当前 `--window-id`。
2. 每次导航、滚动后刷新状态，不能持久化元素索引或固定坐标。
3. 可访问性树可能包含屏幕外的 WebView 内容；“树里有学习记录文字”不代表该处可直接点击。点击未改变页面时先重新观察，不重复盲点。
4. 需要截图定位时先读取截图；Orca 坐标是窗口局部坐标，截图像素坐标须除以 `screenshot.scale`。窗口尺寸或缩放改变后重新定位。
5. 同一时刻只允许一个 agent 操作家长 App。委派后协调者停止点击，避免前台、焦点和索引相互干扰。

### Codex 与 Computer Use 的区分

Codex 是执行任务的 agent，`orca computer` 是桌面控制工具，二者不是同一个东西。用户指定 Codex 优先时按其选择派发，并准确说明实际调用的工具；不能把当前 agent 的 Orca 操作称为“Codex 原生 Computer Use”。

- 派发遵循当前 `orchestration` / `orchestration-ops` 指南，仅派一个 UI worker。
- `agent_unconfigured` 表示 Orca 的 Codex 启动器被禁用或不可用；即使 shell 能运行 `codex --version`，也不能证明 Orca 可派发。
- 失败时检查原始错误、Task/Dispatch 与终端状态，避免重复启动。不要自行改全局 agent 配置或偷偷换执行者；回报阻塞，确认启用 Codex或使用其他已可用的桌面控制方式。

## 证据与能力边界

家长 App 首页可提供学习记录、应用使用轨迹和学习计划入口；“学习记录”区域可包含内嵌 WebView。首页展示不等于已进入日报、周报或权限管理页。

官方 [App Store 说明](https://apps.apple.com/cn/app/id1570208252)列有学习报告、调整使用时间、屏蔽娱乐应用、下发资料与学习任务等功能。这只能证明产品声明，不能代替当前账号、型号和版本的可操作性验证。

按本次 UI 分别确认，不事先许诺：

| 能力 | 应取得的最小证据 |
|---|---|
| 近期使用分析 | 可见日期范围、应用汇总及是否完整；只有首页时不能写成近7天趋势 |
| 应用关闭 | 应用管理页的实际条目、当前状态、家长验证与保存方式 |
| 按日限时/分时段 | 控件是否存在、可选值、最小粒度、工作日与周末能否分开 |
| 动画模块单独关闭 | 混合 App 是否支持模块级限制；没有则只能讨论整个 App 限制或陪同使用 |
| 自动连播/推荐关闭 | App 内真实开关；不能假定家长端有该功能 |
| 已保存且已生效 | 保存结果、重新进入后的持久值；设备端未核验时只报“家长端已保存，设备执行未验证” |

公开的星火 API、学习机应用分发开放平台，不等于家长端管控 API。未找到公开接口时只写“未确认”，不宣称绝对不存在。

## 最小只读检查

1. 确认目标孩子/设备和当前学段；避免切到其他家庭成员的数据。不在输出中重复不必要的姓名或设备标识。
2. 优先查看近7天汇总或周报，分清上学日、周末与假期。没有完整汇总时仅报告已看到的日期，不为了凑趋势遍历全部历史。
3. 记录主要应用的时长、时段、是否反复切换、现有限制。日总量不能证明连续观看，应有会话时间或家长观察佐证。
4. 核对实际动画/视频入口。语言学习 App 可能混有练习和视频，不能仅凭名字判定应禁用。
5. 达到支持建议的证据量就停下，输出待确认的调整表，不额外盘点系统、账号、相册或硬件。

### 统计解释

- “学习时长”可能把应用管家、设置等维护活动算进去。维护时长单独列为非教学/归因未明，不直接认定是孩子娱乐。
- 家长或 agent 调试设备的时段不能作为孩子习惯证据；需与家长确认后才排除。不要把无法解释的差额补成观看时长。
- 首页轨迹可能只展示部分事件，分钟取整、实时刷新和不同统计口径也可能造成总数差异。不能直接相加证明完整全天用时。
- 进入英语 App 不代表在学英语；“完成全部环节”不证明掌握。混合 App 的用时也不能全部算动画。
- 连续数日的主要去向、是否挤占睡眠/作业以及能否按约定结束，比单日总时长更适合判断需要怎样调整。不凭观看时长诊断“成瘾”或注意力障碍。

## 一年级上学期的分类方法

依据校内当前进度、实际理解程度和观看方式，而不是仅依据应用宣传年龄或带有“AI/英语”字样。

| 分类 | 判断依据 | 可讨论的管理方式 |
|---|---|---|
| 当前必需学习 | 学校明确使用，或配合当前识字/拼音/朗读、数感和当期计算的短任务 | 保留必要入口，完成具体任务后结束；保留不等于不限时 |
| 主动练习与创作 | 能跟读、作答、动手创作，有适合当前能力的明确任务 | 少量择优保留，短时段使用；不为追求用时增加刷题 |
| 学习与视频混合 | 既有学习环节，又有大量可连续看的内容 | 优先模块级限制；不支持时讨论 App 级限时与陪同使用，不一刀切归为娱乐 |
| 动画/视频娱乐 | 主要被动观看、反复续播、没有明确任务 | 学习时段不开放自由浏览；另设明确的娱乐时间与结束点 |
| 暂不适配内容 | 难度明显超出当前进度，或简单陪同仍难理解且主要追逐画面 | 暂停或换更短、更容易理解的材料，不能只因“是英文”保留无限观看 |
| 系统与管理工具 | 设置、管家、桌面、网络管理等 | 不按学习时长排名直接禁用；需要家长保护的入口只走官方管控方式 |

英语视频不必逐词听懂。更有用的检查是：孩子在画面或家长帮助下能否理解大意、指认熟悉事物、愿意模仿短句。可先选2–5分钟、贴近日常生活的短片，配简短共看互动；不把观看后的复述变成每次必须通过的考试。

大量“进阶”任务同时待完成，也不必推断孩子拖延。先核对任务是否当前需要、是否重复或超纲；减少无关任务需另经家长确认，不自行删计划。

## 调整与验证

下列是可讨论的试行例子，不是医学标准、普适上限或已执行配置：

- 学习机用于一个具体的小任务，一次约10–15分钟后离屏休息；按孩子状态和学校要求调整，不要求填满额度。
- 对正影响作息的自由看动画，先停止学习时段的自由浏览；如家庭仍保留娱乐，可约定一次一集、约10–15分钟的固定窗口，而不是每个视频 App 各给一份额度。
- 有实际开关时关闭自动连播；没有开关则明确工具限制，改用家长选片和约定结束点。
- 睡前留出不看屏幕的缓冲，具体禁用时段依据家庭作息确认，不猜孩子的起床和就寝时间。
- 为到点结束提供预告和线下替代活动，与孩子解释规则。保留合理娱乐，不把 AI 的“专注管理”当作无条件全面剥夺。

修改前给出表格：

| 应用/模块 | 已确认的使用事实 | 原设置 | 拟保留/关闭/限时及参数 | 理由与不确定项 | 恢复办法 |
|---|---|---|---|---|---|

家长确认后再操作，逐项保存、重新进入读取。即刻生效的开关不可当作只读测试。设备离线、同步未确认或返回错误时停止同类写操作，不能重复点击并宣称成功。

几天至一周后可按家长要求复看：连续观看是否减少、能否顺利结束、睡眠/作业是否受到保护、孩子是否仍有兴趣与自主选择。不承诺工具限制能“确保专注”，也不自行建立长期无人值守监控。

## 回报格式

- **已看到**：日期范围、关键应用汇总、现有限制；说明维护活动和缺失记录。
- **建议**：保留/限时/关闭及适龄理由，区分观察、家长描述和推测。
- **执行状态**：未修改 / 家长端已保存 / 设备执行已验证，不能混写。
- **待确认**：具体应用与参数、学校必需工具、家庭作息及无法确定的使用方式。
- **共享文档**：仅更新可复用的操作路径和判断方法，不抄录孩子的原始轨迹。
