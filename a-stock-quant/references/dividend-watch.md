# 红利守望（Dividend Watch）模块

用户个人实盘风格的逆向红利策略，与本平台主线「动量+轮动」策略**平行独立**。

> 状态：已实现。脚本 `scripts/dividend_watch.py`，观察池 `scripts/watchlist.yaml`，
> 每日报告落盘 `data/reports/dividend_watch_YYYYMMDD.md`，状态跨区时推送提醒。

## 架构规则：必须与动量策略平行，不可融合

动量策略买「涨得好」、红利策略买「没人要」，信号方向相反；揉进同一信号体系两边都失效。
正确形态：共享 `datafeed.py` 缓存层（历史日线/parquet），独立信号逻辑、独立报告输出，
**状态跨区时才推送**（微信 relay 主渠道 → 飞书 DM 兜底，复用 investment-monitor 模式，不每日打扰）。

## 策略铁律（用户定版）

1. **无人问津时才买** —— 量化为双轴：估值分位（主）+ 距 52 周高点回撤（主）；
   换手率/量能分位只作辅助，**总市值 ≥3000 亿的超大盘股不作硬门槛**（指数/北向被动盘污染换手信号）。
2. **只买能分红、能回购的公司** —— 股息率 TTM ≥4%、超十年国债 ≥1.5pct、有回购公告加分。
3. 候选池限定央企/国企/有护城河公司；**「温和增长」不是硬性要求**（用户 2026-10-24 明确剔除），
   周期股不因此被排除，但进独立评估桶（见下）。
4. 目标年化 ~7-8%（跑赢理财即可），持仓 ≥半年，调仓提示月度级，不追热点不交手续费。

## 数据源分工（免费源，可用性 2026-10 验证）

| 指标 | 数据源 | 回答的问题 |
|---|---|---|
| PE-TTM / PB 十年分位 | 百度估值接口（红利桶看 PE，周期桶看 PB） | 便宜吗 |
| 总市值 | 百度估值接口 | 是否超大盘（量能门槛豁免判定） |
| 股息率TTM + 连续分红年数 | 巨潮分红明细 | 能分红吗 |
| 股息率自身历史中位 | 巨潮分红明细 × baostock **不复权**价（除息日时点） | 股息是否还划算 |
| 量能/价格 250 日分位与距高点 | baostock（复用 datafeed 前复权缓存） | 无人问津吗 |
| 股息率 − 十年国债收益率 | akshare `bond_zh_us_rate` | 比理财值多少（用户的收益锚） |
| 回购公告 | akshare `stock_repurchase_em` | 能回购吗 |

注意：datafeed 的 parquet 缓存按代码命名、不含复权方式，**算历史股息率的不复权价必须另发
裸查询、禁止走 get_hist(adjust="3")**，否则污染前复权底仓（dividend_watch.raw_closes 即此实现）。

## 信号分区（脚本 judge() 的实现口径）

- 🟢 买入区（须同时满足）：
  - 估值分位 ≤30%，**或**（分位 ≤40% 且 距 52 周高点回撤 ≥15%）
  - 股息率 TTM ≥4%
  - 股息率 − 十年国债 ≥1.5pct（国债数据缺失时该门槛跳过并标注）
  - 量能分位 ≤40%（总市值 ≥3000 亿豁免）
- 🟡 观望：估值分位 ≤60% 但未全过买入门槛（报告列出具体未过项）
- 🟠 持有不加：估值分位 60~80%，或 >80% 但股息率仍高于自身历史中位
- 🔴 减仓提示：估值分位 >80% **且** 股息率跌破自身历史中位
- ⚠️ 价值陷阱告警：估值分位 ≥70% 且 250 日涨幅 ≤0 = 盈利下滑把分位顶高（不是变便宜），只告警不自动剔除
- ⚠️ 数据告警：股息率 TTM 日环比突变 ≥2pct → 提示人工复核（防特别分红一次性干扰）
- 分位数据 <5 年（回 A 时间短，如移动/海油）一律标注「分位数据<5年」，降可信度

所有阈值在 `dividend_watch.py` 的 `PARAMS` 字典，改完直接重跑验证。

## 运行方式

```bash
cd scripts
python dividend_watch.py                 # 每日跑：落盘报告，跨区才推送
python dividend_watch.py --force-notify  # 强制推送当日全览 (验证通知链路)
python dividend_watch.py --no-notify     # 只落盘不通知
```

agenda 任务：每日 21:40（在 daily_review 之后跑，复用其已热的 baostock 缓存）。
密钥经 wrapper 注入环境变量：`FEISHU_APP_SECRET` / `CHAT_HUB_RELAY_TOKEN`（不入库）。
首日运行为基线建立，不产生跨区通知。
