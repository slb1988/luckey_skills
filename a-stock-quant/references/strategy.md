# 策略完整规则与学术依据

## 为什么非短线 (学术依据)

A股因子结构与美股相反，决定了不能做日内/隔日追涨：

| 期限 | A股实证 | 含义 |
|---|---|---|
| 日内/周内 | **强反转** | 追昨日涨停/今日大涨 = 大概率被反噬 |
| 月度 | 动量基本消失 | 单纯"上月最强"无效 |
| 中期(60-120日形成,持有数日-数周) | 较弱但存在的动量 | **我们利用的窗口** |
| 长期(>2-3年) | 反转 | 超买回归 |

证据链：
- NBER w29453: A股月频反转显著(1.2%/月, t=5.57), 散户主导
- 清华五道口《月频动量消失之谜》: T+1制度导致日内动量+隔夜反转抵消
- 交易成本铁律: 印花税0.05%(卖出), 年换手200%约损耗10%收益

**结论**: 最优窗口 = 中期动量(跳过最近5日规避短期反转) + 周频调仓(压换手)。

## 三层结构

### ①市场闸门 (仓位总开关)
用沪深300日线判断 (strategy.market_gate):
| 条件 | 仓位上限 |
|---|---|
| 收盘>MA60 且 MA20>MA60 | 90% (满仓档) |
| 收盘>MA60 但 MA20≤MA60 | 50% |
| 收盘<MA60 | 20% (仅守最强) |
| 收盘<MA120 且 MA20<MA60 | 0% (清仓) |

### ②板块轮动 (选主线)
板块得分 = 0.4×RS_Ratio + 0.3×RS_Momentum + 0.3×资金流持续性分
- RS_Ratio: 行业/全指 比值趋势 (RRG横轴)
- RS_Momentum: 比值边际变化 (RRG纵轴), 两者>0=领先象限
- 资金流持续性: 近10日≥6日净流入为正; 排除"单日占比>50%"的一日游
- 选 Top3 主线; 持仓板块跌出 Top6 → 轮出; 新板块需高于在持≥10%才换 (钝化)

### ③个股动量 (主线板块内选股)
Score = 0.5×中期动量 + 0.3×趋势确认 + 0.2×风险调整
- 中期动量: 过去60日涨幅, **跳过最近5日** (规避反转)
- 趋势确认: MA20>MA60 且 收盘>MA20 (不满足直接淘汰)
- 风险调整: 动量/年化波动率 (避免妖股)
- 持5-8只, 单票≤20%, 单板块≤40%, 现金≥10%

## 进出场规则
- 调仓频率: 周频 (周五算信号, 周一开盘成交)
- 买入: 次日开盘价; 开盘涨停/一字则放弃, 资金顺延
- 卖出(任一触发): 止损-8% / 浮盈>15%后回撤-10% / 跌破MA20且拐头 / 板块轮出
- 单日最多新开3只

## 硬过滤 (选股前剔除)
ST/*ST、上市<60交易日次新、当日涨跌停/一字、停牌、20日均额<1亿、价<2元、北交所。
涨跌停幅度: 主板±10%, 创业板/科创±20%, ST±5%。
