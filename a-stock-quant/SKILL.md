# A股量化模拟平台 (a-stock-quant)

非短线的 A股量化模拟炒股系统。策略=「主线动量 + 板块轮动」三层结构，周频调仓，
持仓数日到数周。全套免费数据源，本地纸交易账户，每日采集热点、每日复盘、周一模拟下单。

> ⚠️ 这是**模拟盘 (paper trading)**，不接真实券商资金。所有"成交"都是本地账户记账。
> ⚠️ A股短期是**强反转**（学术实证），所以本策略刻意做中期动量+周频，**不追日内/隔日热点**。

## 何时用本 Skill

- 用户问"今天/这周该买什么"、"复盘一下"、"模拟盘现在如何" → 跑对应脚本
- 用户想"回测策略"、"调参" → 跑 backtest.py
- 用户想"采集今天热点/资金流" → 跑 daily_collect.py
- 用户想了解策略逻辑/数据源 → 看本文件 + references/

## 策略一句话

①**市场闸门**(沪深300 MA20/60/120决定满仓/半仓/空仓) → ②**板块轮动**(行业相对强度+10日资金流持续性,排除一日游,选Top3主线) → ③**个股动量**(主线板块内, 过去60日涨幅【跳过最近5日规避反转】+ MA20>MA60, 选5-8只)。
风控: 止损-8% / 浮盈>15%后回撤-10%止盈 / 单票≤20% / 单板块≤40% / 现金≥10%。
成本: 印花税0.05%(仅卖出)+佣金万2.5+滑点0.15%, 全部如实计入。

详见 `references/strategy.md`。

## 数据源 (全免费, 已验证)

- **baostock** 历史日线底仓 (免token最稳) — 指数代码需显式映射, 见 datafeed._INDEX_MAP
- **akshare** 盘后增强 (行业资金流/涨停池/人气榜/概念) — 15:00后跑, 本地缓存防封IP
- **adata** 准实时 (多源+代理切换) → efinance → akshare 失败转移

详见 `references/data-sources.md`。

## 已知局限 (诚实提示)

- 回测的"板块强度"用成分股价格动量代理, **未用真实资金流持续性层** (为可复现/防封IP妥协)。
  完整策略 alpha 待"每日采集"积累1-2月真实数据后验证。
- 回测股票池=沪深300成分 (避免全市场遍历被封)。扩大池子是调优方向。
- 2024-2026回测: +35.6%, CAGR 13.1%, Sharpe 0.67, MDD -19.5%, 但跑输沪深300(超额-8.2%)。
  胜率33.7%但盈利, 说明止损止盈纪律有效(盈亏比>2)。**策略调优是下阶段工作。**
- A股月度动量本身弱, 超额主要来自板块轮动主线捕捉 + 趋势止损纪律。
- 数据是交易所**延迟行情**, 非付费实时tick。模拟盘足够, 实盘需券商QMT。

## 调参入口

所有参数在 `scripts/strategy.py` 的 `PARAMS` 字典。改完直接重跑 backtest.py 验证。
调优优先级: ①扩大股票池 ②回测引入真实资金流持续性 ③轮换阈值/调仓频率 ④止损位。
