# QNAP NAS 已安装 QPKG 应用

安装路径: `/share/CACHEDEV1_DATA/.qpkg/`

| 目录名 | 应用名 | 用途 |
|--------|--------|------|
| `CacheMount` | HybridMount 底层 | 文件型云网关，挂载云存储到本地 NAS |
| `HybridBackup` | 混合备份中心 | 备份/同步 NAS 数据到云端或远端 NAS |
| `container-station` | Container Station | Docker 容器管理平台 |
| `Entware` | Entware | opkg 包管理器 (提供 git, python 等) |
| `QTransmission3` | Transmission | BT 下载客户端 |
| `PlexMediaServer` | Plex | 媒体服务器 |
| `DownloadStation` | Download Station | QNAP 官方下载站 |
| `MultimediaConsole` | Multimedia Console | 多媒体管理控制台 |
| `VideoStationPro` | Video Station Pro | 视频管理/播放 |
| `PhotoStation` | Photo Station | 照片管理 |
| `photostation2` | Photo Station 2 | 新版照片管理 |
| `QuMagieCore` | QuMagie | AI 智能相册 |
| `MediaSignPlayer` | Media Sign Player | 数字标牌播放器 |
| `QsyncServer` | Qsync Central | 文件同步服务 |
| `Qsirch` | Qsirch | 全文搜索引擎 |
| `QDMS` | QDMS | 数字媒体服务器 |
| `Qfiling` | Qfiling | 自动文件归档 |
| `Qboost` | Qboost | NAS 性能优化 |
| `QKVM` / `.QKVM` | QKVM | 虚拟机管理 |
| `NaviDrome` | Navidrome | 音乐流媒体服务器 |
| `CloudLink` | myQNAPcloud Link | 远程访问 NAS |
| `MalwareRemover` | Malware Remover | 恶意软件扫描 |
| `BaiduNetdisk` | 百度网盘 | 百度网盘同步 |
| `xunlei-pan` | 迅雷云盘 | 迅雷云盘挂载 |
| `owapp` | owapp | (系统组件) |
| `.@qRPlayCenter` | qRPlay Center | 远程播放中心 |
