# 客户端运行时行为

代码：`Tools/ue-launcher/src-tauri/src/lib.rs`、`toolbox.rs`、`toolbox_portable.rs`、`toolbox_discovery.rs` + `src/App.tsx`。权威文档：`references/toolbox.md`。

## 目录拉取

- `settings.toolboxManifestUrl`：新用户/旧空值默认 `http://192.168.2.13:5000/ue-launcher/tools`；旧值裸 `IP:端口` 或服务根自动规范化为完整路径；完整自定义 URL 保留不被覆盖；明显无效输入在设置里明确报错。
- 启动先用本地缓存渲染，进入工具箱/后台任务自动刷新；手动刷新保留。请求合并节流，无服务器推送。
- 拉取失败显示原因+缓存时间，不覆盖最后有效缓存；已安装软件离线仍可启动。
- 解包：`status.code==0` 包装或裸 manifest 都接受；schemaVersion 必须 1，拒绝 2。

## 状态机（canRun 驱动）

| 状态 | 展示 | 点击 |
|---|---|---|
| 未安装/程序丢失 | 灰、可点击、提示"点击安装" | 下载→校验→安装/部署 |
| 下载中 | 灰+进度 | 不重复下载 |
| 已下载未就绪 | 灰、提示"继续安装" | 用已校验缓存包 |
| 安装中/等待检测 | 灰 | 防重入，可手动重新检测 |
| 可运行 | 彩、提示"点击打开" | 启动本机程序 |
| 失败/取消 | 灰+错误 | 不误报成功，可重试 |

tips：悬浮显示 name + description + 当前状态；图标失败回退默认图标不影响灰彩。

## 安装会话与就绪检测

- 同 ID 防重入，2 秒轮询，10 分钟上限；"安装器已启动"≠"已就绪"，最终以程序检测为准。
- 引导安装器（提前退出的）保守处理：无法确认完成就不抢跑，给手动重新检测。
- 显式点击的准备完成后启动一次；意图不重放（焦点恢复/重启/状态事件不重复拉起）。
- EXE 740 回退：普通 spawn 失败 → PowerShell `Start-Process -Verb RunAs`（路径参数以数据传递）；只提升已校验安装器，不提升 Launcher/便携程序。UAC 取消/拒绝单列不冒充成功。

## 本机识别链（优先级）

1. **显式绑定**（`toolbox_bindings.json`，ID→真实 EXE，本机文件不上传）——失效时不静默改绑其他实例；点击安装先提示修复/替换，确认后验证新目标成功才原子改绑。
2. 已完成的受管便携部署（读完成标记）。
3. `launchCandidates`（环境变量 `%LOCALAPPDATA%`/`%APPDATA%`/`%ProgramFiles%` 等展开，验证绝对路径+文件+MZ/PE，排除安装包缓存）。
4. 本机手动快捷方式的真实目标；按声明 EXE basename 查 App Paths。
5. 定向卸载登记（HKCU/HKLM 32/64 视图，InstallLocation+入口或 DisplayIcon；PowerShell 只读查询，不提权、不执行 UninstallString、不用 Win32_Product、不做全机扫描）。
6. 歧义/失效 → 复用"选择已安装程序"手选绑定。

Notepad++ 实测：HKLM App Paths 64/32 视图均返回 `D:\Program Files\Notepad++\notepad++.exe`——非默认盘路径靠登记可查，不靠猜。

## 同名 EXE 去重

同名（basename 不区分大小写）只建立**关联候选**：规范真实路径相同或经显式绑定确认后才合并；同名多路径/产品冲突不静默隐藏，让用户确认。合并时保留手动工具的参数/工作目录/图标/排序；动作按"来源+ID"定位避免误路由；只合并展示，不删本机记录/绑定/服务端条目。

## 更新边界（首版）

服务器发布新 version/hash 后仍运行原绑定，不自动下载/升级/提示；详情区分"目录版本"与"本机路径"；更新=用户外部准备新版后复用手选改绑。无内置升级/卸载。
