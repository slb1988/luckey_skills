# Luckey 小Key IP

## 角色定义

小Key是 `luckey-illustration` 中文正文配图的固定视觉 IP。

默认每张图都要出现小Key。小Key不是吉祥物，不是贴纸，不是可爱装饰，而是正在认真参与系统运转的荒诞工作者。

## 外形

- 白色或近白色豆形小人，轮廓像圆润豆子、钥匙孔或小幽默工位助手。
- 黑色墨镜/眼镜是固定识别点。默认用简化黑色圆角墨镜，不画复杂五官；需要表情时只给一条很小的嘴线。
- 头顶必须有一把小金钥匙，这是 Luckey 的核心符号。钥匙要简化、清楚、可读，不要画成复杂首饰。
- 短手短腿，黑色小鞋。手脚存在感低，服务动作，不抢主体。
- 身体轮廓略微不规则，有手绘感；不要过度精致、过度 3D、过度商业吉祥物。
- 气质冷静、认真、略笨拙，有一点戴墨镜的冷幽默。

## 性格

- 很认真，但做的事有点荒诞。
- 像一个低调的系统操作员。
- 冷幽默，不卖萌；墨镜让它有一点“看起来很稳，其实正在努力”的反差。
- 有点笨拙，但不蠢。
- 像在白板草图里真的负责某个工作。

## 常见职责

让小Key承担核心动作：

- 搬运素材。
- 拉线汇聚信息源。
- 卡在断点里。
- 在机器里操作“判断”杆。
- 变成筛选漏斗。
- 切开“素材鱼”。
- 盖章承接话术。
- 牵着承接路径。
- 举警告牌看坑。
- 从洞里伸手但接不住内容。
- 在旁边搬砖、搭桥、开门、分拣、记录。
- 用头顶钥匙开门、解锁箱子、打开断点、拧动怪机器。

## 禁止

- 不要把小Key画成过度可爱的吉祥物。
- 不要画成儿童卡通角色。
- 不要画成黑色实心小怪物；默认是白色豆形身体、黑色墨镜、金色钥匙。
- 不要给小Key复杂服装、表情包、闪亮眼睛。
- 不要让钥匙消失、变得太小或看不出是钥匙。
- 不要把墨镜画得过度写实、厚重或像时尚广告。
- 不要让小Key只是站在角落里看。
- 不要让小Key抢走结构表达。
- 不要把小Key画得太商业、太圆润、太精致。

## 判断标准

如果去掉小Key，图的核心隐喻还能完全成立，说明小Key太装饰了；要重写提示词，让小Key成为动作主体。
