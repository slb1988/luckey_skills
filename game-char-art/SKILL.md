# 游戏角色立绘出图 Agent

把策划给的角色 prompt（共用底子 + 角色块结构）落地为实际图片，流程：**拼 prompt → API 出图 → 校对 → 选定归档**。

## 前置条件

- 环境变量 `ARK_API_KEY`（火山引擎 Ark 控制台申请，Seedream/即梦模型走这里）。未设置时提示用户设置，不要索要或打印 key 内容。
- `pip install requests`（一般已装）。

## 标准流程

1. **读设定**：`references/base-style.md`（共用底子，所有角色共用）+ `references/characters.md`（角色块与五行锁定表）。
   - 五行归属以锁定表为准（如 姜子牙=金 已锁死，木/土已否）。新角色先和用户对齐五行再写角色块。
   - 用户直接给出新角色块时，追加进 `references/characters.md` 再出图，保持设定单一来源。
2. **拼 prompt**：`共用底子全文` + `目标角色块全文`，原样拼接，不要改写措辞（措辞是校过母题的）。
3. **出图**：每角色默认出 4 张（"出 4 选 1"）：
   ```bash
   python .claude/skills/game-char-art/scripts/seedream_gen.py \
     --prompt-file <拼好的prompt.txt> \
     --out-dir "luckey/09_generated/char_art/<role-slug>" \
     --name <role-slug> --n 4 --size 2048x2048
   ```
   - 同时把完整 prompt 存成同目录 `prompt.md`，保证可复跑。
4. **校对**：用 Read 工具逐张看图，按下面清单过；全跑偏就改 prompt 重 roll，不要硬选。
5. **选定**：列出 4 张的校对结论，让用户挑 1 张（或用户授权时给推荐）。选定后在 `prompt.md` 里记录 `selected: <文件名>`。

## 校对清单（每张都过）

- **血统色**：主色 = 五行血统色（金=鎏金/琥珀/玄金，木=青绿，水=冰蓝/月白/银，火=朱红/赤金，土=赭黄/岩褐）。主色跑偏 = 不合格。
- **厚涂正不正**：国风厚涂半厚涂 + 敦煌重彩 + 金线勾边 + 金箔 + 颗粒纸纹。出现 Q 版/赛璐璐/扁平矢量/写实 3A/3D 渲染感 = 不合格。
- **气质走位**：对照角色块末尾的气质关键词（如姜子牙=沉稳/谋略/统帅感，悟空=张扬/狂/爆发感，白素贞=温柔缱绻+压迫感）。
- **构图**：竖版半身占约 60% 居中，头顶留白（放阶级星数），底部血统色光晕。
- **禁项**：文字、字幕、水印、多余手指、黑白线稿。--watermark 默认已关，图里仍出现水印样式要标记。

## 脚本参数

`scripts/seedream_gen.py`：

| 参数 | 默认 | 说明 |
|------|------|------|
| `--prompt` / `--prompt-file` | 必填其一 | prompt 文本或文件路径 |
| `--out-dir` | 必填 | 图片输出目录（自动创建） |
| `--name` | `char` | 文件名前缀，产出 `<name>-1.png …` |
| `--n` | 4 | 张数（逐次调用，互相独立） |
| `--size` | `2048x2048` | 1:1 用 2048x2048；也支持 `1K/2K/4K` |
| `--model` | `doubao-seedream-4-0-250828` | Ark 上的 Seedream 模型 ID |

失败自动重试 2 次；结束打印已保存文件的 JSON 清单。

## 归档约定

- 图存 `luckey/09_generated/char_art/<role-slug>/`（可重新生成的派生内容，角色 slug 用 kebab-case，如 `jiang-ziya`）。
- 选定后的成品若被策划/项目正式采用，再由用户决定复制进 `07_assets` 或项目目录——本 skill 不自动搬。
- prompt 与选定记录随图存同目录 `prompt.md`，方便复跑和追母题。
