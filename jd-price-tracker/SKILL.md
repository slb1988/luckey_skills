# 京东塔式 PC 采购比价

目标：在用户需要机器前，盯着一套固定配置的价格，找到值得买、能同时买齐、售后可靠的窗口。**只调研和提醒，绝不下单。不预测市场最低点，只陈述历史相对位置。**

## 数据与维护边界

- 跟踪候选与 SKU 清单：[references/components.md](references/components.md)——调整跟踪对象只改这个文件。
- 每日价格日志：`luckey/06_life/home/tower-pc/price-log.csv`（只追加）。
- 汇总判断与决策：`luckey/06_life/home/tower-pc/pc-build-tracker.md`。
- 项目运行手册（含入手价确认状态）：`.claude/plans/京东塔式PC采购监控.md`。

## 环境前提

- 浏览器：Orca 内嵌浏览器（`orca` CLI）。京东登录态与慢慢买登录态都保存在其 profile，跨会话复用。
- 用 `scripts/orca_page.sh <url-substring> [create-url]` 取得可用标签页的 browserPageId；不要硬编码 page id（每次会话会变）。
- 掉登录处理：京东掉登录→让用户在 Orca 窗口里直接扫码或密码登录（二维码截图转发会被风控，禁止截图转发）；慢慢买→微信扫码。**绝不向用户索要或代填密码。**

## 渠道与口径纪律（硬性）

- 只跟京东自营、品牌官方商城、官方旗舰店，全新国行有保；排除二手、拆机、翻新、以旧换新价。
- 人人可买价是基准：地区补贴（国补）、PLUS 价、限人群券单列记录，不混入基准。
- 板 U 套装不重复计价；渠道报价只作背景，不冒充零售价；缺价标「缺价」，禁止估算凑总价。
- 登录后不可见、缺货、无法核实，如实记录，不编数据。

## 每日流程（静默执行，触发才出声）

1. `scripts/orca_page.sh` 拿到京东 tab；验证登录态（搜一次未跳登录页即可）。
2. 对重点部件逐个取价：CPU（含板 U 套装）、内存全部候选（2×64/2×48/2×32）、两张显卡。
   - 优先 `scripts/jd_search.sh "<关键词>"`（结果含 SKU、标题、到手价、促销、店铺）；
   - 价格或库存存疑再 `scripts/jd_item.sh <sku>` 开商品页核实（含加购按钮/仅剩 N 件/补贴）。
3. 每周一次补查非重点件（主板/SSD/电源/散热/机箱）并核库存。
4. 重点件用 `scripts/mmb_curve.sh <商品URL> 90` 取慢慢买 90 日曲线，交叉确认「历史相对位置」。
5. 按 `components.md` 的列把记录追加进 price-log.csv。
6. 计算两档整机价（基础档/加强档，主板 B850 为基准），与历史对比。

## 触发提醒（满足任一立即发，附直链与曲线依据）

1. 同套整机比过去 14 天有效日中位价便宜 ≥1,000 元（需 ≥7 个有效日数据）；
2. 同款内存或显卡降幅 ≥8% 且省 ≥500 元；
3. 整机或部件达到用户确认的入手价；
4. 重点部件创近 30 日新低（自有日志 + 慢慢买曲线交叉确认）；
5. 价格回到近 90 日最低 5% 分位。
同价不重复提醒；发整机提醒前重新核实全套可买。只表述「历史相对低位」，不把短期下跌说成未来一定还跌。

## 周报（每周一次，固定短格式）

```
基础档 ¥X / 加强档 ¥Y ｜ 相比上周 ±Z ｜ 动的是：部件名（±金额）
买 or 等：一句话 + 依据（曲线位置/触发状态，不预测）
备选观察：有则一行（新 CPU/板U套装/代装方案，说明理由，不换基准）
```

## 反限流与稳定性

- 京东高频查询会触发「PC频控页」或空结果：搜索间隔 ≥5s、商品页间隔 ≥8s；触发后停 1-2 分钟再继续。
- `jd_search.sh` 输出「EMPTY」多为限流，不是真没货；稍候重试再下结论。
- www.jd.com 会按地区跳 global.jd.com，始终用 search.jd.com / item.jd.com 深链。
- 页面结构变更（如 `.plugin_goodsCardWrapper` 消失）时，先在浏览器里 `orca eval` 探明新结构再改 `scripts/jd_extract.js`，并记录变化。

## 推荐话术纪律

- 默认推荐基础档（5060 Ti 16G）：用户优先级是编译/内存/稳定安静，显卡次要。
- 整机总价要拆出「内存占比」：DDR5 处历史高位是总价超预算的主因，说清但不承诺回落时点。
- 发现明显更划算的新 CPU、板 U 套装、带整机保修的代装方案：单列入备选观察并给理由，不悄悄替换跟踪基准。
